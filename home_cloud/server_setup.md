# Server Setup

The setup is intentionally compact, making it easy to maintain and relocate.

## Hardware

- Make: Dell Inc.
- Model: Optiplex 3050 Micro
- CPU: Intel i3-6100T 2c/4t 3.2GHz
- GPU: Intel HD 530
- RAM: 32GB DDR4-2133
- SSD0: 512GB NVMe M.2 SSD
- SSD1: 1TB SATA 2.5in SSD

## Software

OS: Rocky Linux 10
Purpose: Run podman containers to self-host applications. See [[#Applications]]

### Applications

- Jellyfin
- qBittorrent
- Sonarr
- Radarr 
- Prowlarr
