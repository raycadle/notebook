# Home Server

My home server is a Dell Optiplex 3050 Micro with a 2c/4t i3-6100T processor, 32GB of RAM, and 1.5TB of flash storage (512GB NVMe + 1TB SATA 2.5in). I have a few plans for upgrades for it, but for now it will get the job done quite fine.

Its main purpose is to download and stream my media library, act as always online syncthing client, and whatever else I feel like using it for.
